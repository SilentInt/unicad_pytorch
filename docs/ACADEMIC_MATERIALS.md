# 基于前向因果预测的无人机异常检测

## 与 Galaxy/UnicAD 聚类算法的结合与改进

---

## 一、背景与问题

将 Galaxy 聚类异常检测模型应用于无人机飞行数据异常检测。涉及两类平台、10 种故障类型：

| 数据集 | 平台 | 故障类型 | 序列数 | 特征 | 核心难点 |
|--------|------|---------|--------|------|---------|
| ALFA | Carbon Z 固定翼 (实飞) | 4 种执行器故障 | 46 | 21D @ 10Hz | 部分故障"卡中位"不可见 |
| Basic | 四旋翼 (SITL 仿真) | 6 种传感器故障 | 70 | 47D @ 10Hz | 数据量大，渐变故障 |

**核心挑战**：原始时序数据直接送入 Galaxy，简单线性 AE 仅 ~60% 准确率。需要解决两个问题：
1. 如何从时序数据中提取适合聚类异常检测的特征
2. Galaxy 的 AE+SMM 管线是否必要，能否简化

---

## 二、Galaxy 聚类算法回顾

### 2.1 算法概要

Galaxy/UnicAD 将异常检测建模为聚类任务，核心思想：

1. **AE 预训练**：Encoder→Decoder，将数据映射到低维隐空间
2. **引力场建模**：SMM (Student-t Mixture Model, ν=1) 拟合隐空间分布，K 个聚类中心视为引力源
3. **异常评分 (GOF)**：数据点远离所有中心 → 引力小 → 异常评分高

```
score(z_i) = −log(force) = −logsumexp_k(log F_ik)
log F_ik = log(ω_k) − log(π) − ½log|Σ_k| − log(1 + D²_M(z_i, μ_k))
D²_M = Σ_d (z_id − μ_kd)² / σ²_kd
```

4. **迭代 EM**：排除 top outlier_ratio% 异常 → 微调 AE (recon + gravity loss) → 重拟合 SMM

### 2.2 重实现中的三处修复

在 PyTorch 重实现过程中，发现并修复了三处算法错误：

| # | 问题 | 修复 | 影响 |
|---|------|------|------|
| 1 | SMM scale factor: u_ik 分子用 ν+D 而非 ν+1 | u_ik = (ν+1)/(ν+D²_M) | D=128 时分子 129 vs 2，原型严重退化 |
| 2 | Gravity loss 符号错误，梯度方向反了 | loss = recon + (−J) | 修复前在最小化似然而非最大化 |
| 3 | EM 中用旧编码器嵌入更新原型 | 强制重编码 Z=None | 原型拟合在正确的嵌入上 |

修复后 benchmark 验证：thyroid AUC 0.878→0.965，Ionosphere 0.665→0.937。

## 三、从聚类到无人机异常检测：我的方案

### 3.1 整体架构

核心思路：**用前向因果预测提取特征 → 在特征空间做异常检测**。

```
原始时序 x_{t-75:t-1}, cmd_t
        │
        ▼
┌──────────────────────────────────┐
│ ConditionalGRU (前向因果预测器)    │  ← 核心创新
│ predict(response_t | history, cmd) │
│ 仅用正常数据训练                    │
└────────────────┬─────────────────┘
                 │ 残差 e = (resp − resp̂)²
                 ▼
┌──────────────────────────────────┐
│ 双尺度窗口统计 (mean/std/max)      │
│ W=10 (1s) + W=30 (3s)            │
└────────────────┬─────────────────┘
                 │ 78D/240D 特征
                 ▼
┌──────────────────────────────────┐
│ 马氏距离异常检测                   │  ← 替代 Galaxy AE+SMM
│ score = (x−μ)ᵀ Σ⁻¹ (x−μ)        │
│ 解析解，无需训练                    │
└──────────────────────────────────┘
```

### 3.2 ConditionalGRU：前向因果预测器

**设计动机**：无人机是因果系统——舵面指令（因）→ 飞行器响应（果）。故障破坏这个因果关系。

**结构**：

```
输入: x_{t-75:t-1} (历史 75 帧, 包含全部通道)
      cmd_t        (当前指令: 舵面指令/目标姿态)
      ↓
GRU(feat_dim → 64, 2 层)
      ↓
h_t (隐状态, 已编码历史飞行模式)
      ↓  concat(h_t, cmd_t)
FC → ReLU → FC → resp̂_t (预测当前响应)
```

**为什么这样设计**：

1. **仅用正常数据训练** → 模型学会的是"给定指令下的期望响应"→ 故障时预测误差自然增大
2. **指令条件显式注入** → 消除正常机动（转弯/爬升）的"伪异常"残差。不注入指令时，无条件预测器在正常转弯时也会产生大残差
3. **GRU 而非 Transformer/LSTM/TCN**：39K 训练样本下，GRU 简洁的门控机制（仅 reset+update）最优。LSTM 的 forget gate 和 memory cell、TCN 的膨胀卷积在小数据上都是负担

**特征通道设计**：将 21 维通道分为三类：

| 角色 | 通道 | 用途 |
|------|------|------|
| 响应 (13D) | IMU + 导航误差 + 跟踪误差 | 预测目标——故障时这些值偏离指令预期 |
| 指令 (5D) | 舵面 PWM 指令 | 显式注入预测头——告诉模型"飞行员想做什么" |
| 输入 (3D) | 油门/高度/爬升率 | 提供飞行状态上下文 |

将 cmd−meas（指令−测量误差）作为响应通道而非原始测量值，是关键的领域知识注入。消融实验证实原始测量值反而稀释训练信号。

### 3.3 特征工程：从瞬时残差到时序模式

单帧残差 e_t = (resp_t − resp̂_t)² 噪声大——正常转弯时个别通道也会有大残差。需要通过局部时序统计来区分"正常偶尔大"和"故障持续大"。

```
e_t (13D/40D)
  ↓ z-score 归一化 (μ, σ 从正常帧估计)
  ↓
双尺度滑动窗口:
  W=10 (1s): [mean, std, max] → 39D/120D  捕获快速瞬变
  W=30 (3s): [mean, std, max] → 39D/120D  捕获持续异常
  ↓
concat → 78D (ALFA) / 240D (Basic)
```

**为什么是 mean/std/max**：
- mean：信号的平均偏差水平
- std：波动/不稳定程度——故障常伴随异常抖动
- max：峰值异常——捕获瞬态冲击

**为什么跳过残差直接聚类不行**：直接用 GRU 隐状态（135D）聚类 MeanSeq AUC 仅 0.878，远低于窗口统计的 0.936。隐状态学的是"如何预测"，不是"什么是异常"。残差 → 统计这一路径不可替代。

### 3.4 检测器选择：为什么用马氏距离替代 Galaxy

最初使用 Galaxy 的完整管线（AE 扩展 78→128→64 + SMM k=5 + GOF）。但在分析 SMM 聚类结果时发现了系统性问题：

**SMM 在两个数据集上均坍缩为单簇**：

```
ALFA (k=5):  簇0=0, 簇1=35,980, 簇2=0, 簇3=0, 簇4=0
Basic (k=5): 簇0=0, 簇1=0,     簇2=0, 簇3=18,718, 簇4=0
```

Gravity loss 最小化 −log(force) 意味着最大化引力——所有正常帧被强行吸入同一个簇。k=5 中 4 个空置，实际退化为 k=1。

**此时 Galaxy 等价于**："到唯一簇中心的多维马氏距离"——协方差矩阵逆就是最优解。

| 检测器 | ALFA MSeq | Basic MSeq | 训练 | 参数 |
|--------|-----------|------------|------|------|
| Galaxy AE+SMM k=5 | 0.945 | 0.938 | ~100s | ~50K |
| Deep SVDD | — | 0.939 | ~70s | ~150K |
| **马氏距离** | **0.951** | **0.952** | **0s** | **d² 矩阵** |

马氏距离在两个数据集上均优于 Galaxy，且无需训练。这验证了一个重要观点：**特征空间足够规范时，解析解优于神经网络聚类**。

## 四、消融实验（精简）

### 4.1 特征：条件残差不可替代

| 操作 | MeanSeq AUC Δ | 结论 |
|------|--------------|------|
| 删除条件残差（仅用无条件时序残差）| **−0.014** | 唯一有害删除 |
| 删除 FFT/互相关/协方差 (231D→78D) | **+0.016** | 手工特征全冗余，删除反而提升 |
| 删除窗口统计 | −0.254 | 必要，但 mean/std/max 三统计量已足够 |

### 4.2 编码器：GRU 最优

GRU(0.932) > LSTM(0.909) > Conv1d(0.886) > TCN(0.815)。GRU 简洁门控在 39K 小样本上最优。

### 4.3 时序：长窗口 + 单步指令

- 历史窗口：hist=75 (7.5s) 最优，覆盖完整机动周期，样本仅减 7.7%
- 指令窗口：K=1（仅当前指令）最优。更大指令窗口单调有害（AUC 递减至 −0.042）——GRU 隐状态已编码指令历史
- 模型容量：增大即过拟合（hidden 64→128: −0.049，2层→3层: −0.024）

### 4.4 AE 模式：扩展 > 压缩，但不必要

扩展 78→128→64 (+0.004) > 恒等 78→78→39 (0) > 压缩 78→32→16 (−0.011)。但马氏距离跳过 AE 后性能更好 (+0.006 over AE)，说明 AE 非必需。

## 六、核心发现与讨论

### 6.1 对 Galaxy/UnicAD 聚类算法的观察

1. **SMM 在两个独立数据集上系统性坍缩为单簇**。这不是数据问题——Gravity loss 的数学结构（最大化引力）决定了它必然将正常帧压缩到单一紧致簇中
2. **当 SMM 退化为 k=1 时，Galaxy 等价于马氏距离**。AE 的作用是学习一个使正常帧近似高斯分布的隐空间——但当输入特征已经足够规范（z-score + 窗口统计）时，AE 的变换是冗余的
3. **建议**：对于特征空间已经接近多元正态的数据，直接使用马氏距离更高效、更可解释

### 6.2 方法适用边界

- **ConditionalGRU 的前提**：系统存在明确的因果结构（指令→响应）。适用于所有闭环控制系统
- **马氏距离的前提**：正常数据近似多元正态。z-score + 窗口统计使这一条件易于满足
- **不适用场景**："卡中位"等仅在特定条件下暴露的故障，纯数据驱动方法有本质局限

### 6.3 设计原则

1. **前向因果预测 > 相关性建模**：ConditionalGRU 的条件残差是唯一不可替代的信号源
2. **残差路径不可跳过**：窗口统计 > 隐状态聚类。跳过残差直接聚类效果最差
3. **领域知识注入 > 纯数据驱动**：cmd−meas 预处理、通道角色分离均带来显著增益
4. **解析解 > 神经网络聚类**：当特征空间规范时，协方差矩阵逆即最优解
5. **极简 > 复杂**：最终方案仅 3 组件 (GRU + 窗口统计 + 马氏距离)，47K 参数
