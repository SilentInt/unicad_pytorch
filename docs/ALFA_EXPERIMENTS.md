# ALFA 异常检测实验全记录

## 数据集

Carbon Z 固定翼无人机 ALFA 数据集。46 序列 (10 正常 / 36 故障)，47,104 帧，7,674 故障帧 (16.3%)，10 Hz 统一采样。

故障类型：发动机 (23 seq)、副翼 (8 seq)、方向舵 (3 seq)、升降舵 (2 seq)。

---

## 最终模型 (V7)

### 架构

```
原始 21D (10 Hz)
  │
  ▼
┌──────────────────────────────────────────────────┐
│ ConditionalGRU                                   │
│ predict(response_t | x_{t-75:t-1}, command_t)    │
│ 75 帧 (7.5s) 历史窗口, GRU(21→64, 2层), 47K    │
│ concat(h_t, cmd_t[5D]) → FC → resp̂_t[13D]       │
└──────────────────────┬───────────────────────────┘
                       │ (resp_t − resp̂_t)² → 13D
                       ▼
┌──────────────────────────────────────────────────┐
│ Z-score 归一化 → 双尺度窗口统计                   │
│ W=10 (1s): mean/std/max → 39D                    │
│ W=30 (3s): mean/std/max → 39D                    │
│ → 78D                                            │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────┐
│ Galaxy AE 扩展 78→128→64 → SMM(k=5) → GOF(vector)│
│ ~50K params                                      │
└──────────────────────────────────────────────────┘

总参数: ~97K | 训练时间: ~100s (GPU)
```

### 输入通道

| 索引 | 通道 | 来源 | 角色 |
|------|------|------|------|
| 0-5 | angular_velocity.xyz, linear_acceleration.xyz | IMU | 响应 |
| 6-9 | cmd−meas (roll/pitch/yaw/aspd) | nav_info | 响应 |
| 10-12 | alt_error, aspd_error, xtrack_error | nav_errors | 响应 |
| 13-17 | channels1-5 (俯仰/油门/偏航/副翼) | rc-out | 指令 |
| 18-20 | throttle, altitude, climb | vfr_hud | 输入 |

### SMM 退化验证

Galaxy k=5 在 ALFA 78D 特征上也退化为单簇:

```
簇0:      0 (0.0%)  ← 空
簇1: 35,980 (100%)  ← 所有正常帧
簇2:      0 (0.0%)  ← 空
簇3:      0 (0.0%)  ← 空
簇4:      0 (0.0%)  ← 空
```

与 Basic 数据集完全一致。Gravity loss 将 ALFA 正常帧也压缩到单一紧致簇中。

仅 3 个序列 AUC < 0.8，均为"卡在中位"故障。

## 版本演进

| 版本 | 架构 | MSeq AUC | 关键发现 |
|------|------|---------|---------|
| V3 | 双GRU + 309D手工特征 + Galaxy AE | 0.908 | 时序残差加噪 |
| V4 | Transformer掩码通道预测 | 0.892 | 通道互预测性差 |
| V5 | ErrorSequenceGRU + 直接SMM | 0.897 | GRU学不到有效误差模式 |

| V7 (hist=30) | 单GRU + 78D + SMM | 0.935 | 更长历史有价值 |
| **V7 (hist=75)** | **单GRU + 78D + Galaxy AE** | **0.945** | **最优** |

## 消融实验完整结果

### 309D 特征消融

```
基准 Full 309D (V3)                 0.901    —
 78D conditional-ws only           0.917   +0.016  ← 最优子集
120D no temporal-ws                0.911   +0.010
267D window-stats only             0.907   +0.006
 34D raw errors only               0.896   −0.005
189D temporal-ws only              0.893   −0.008
231D no conditional-ws             0.887   −0.014  ← 唯一有害删除
 42D no window-stats               0.647   −0.254
```

结论：ConditionalGRU 条件残差是唯一不可删除的信号源。309D 中 231D 纯属加噪。

### AE 模式消融 (78D 固定)

```
SMM direct (no AE)                 0.932    —
AE compress 78→32→16               0.921   −0.011
AE identity 78→78→39               0.932    0.000
AE expand  78→128→64               0.936   +0.004  ← 最优
AE expand  78→256→128              0.936    0.000
```

结论：AE 应扩展不应压缩。78→128→64 为 gravity loss 提供更多维度。

### 编码器消融 (hist=10)

```
GRU 64,2L                          0.932    —
LSTM 64,2L                         0.909   −0.023
Conv1d k3,3L                       0.886   −0.046
TCN residual k3,4L                 0.815   −0.117
TCN simple k3,4L                   0.909   −0.023
Conv+GRU hybrid                    0.892   −0.040
```

结论：GRU 稠密循环连接对小样本时序最优。

### 历史窗口大小消融

```
hist=10 (1.0s, 38,907 样本)       0.932    —
hist=20 (2.0s, 38,447)            0.932    0.000
hist=30 (3.0s, 37,987)            0.935   +0.003
```

结论：75 帧 (7.5s) 覆盖完整机动周期，训练样本仅减 7.7%。

### GRU 容量消融 (hist=10)

```
GRU 64,2L                          0.932    —
GRU 128,2L                         0.883   −0.049

```

结论：39K 样本支撑不了更大模型。当前 47K 参数恰在数据量边缘上。

### 指令窗口消融


结论：cmd−meas 预处理是最优表示，原始通道稀释 GRU 训练信号。


## 核心设计原则

1. **前向因果预测是核心**：ConditionalGRU 不可替代，天然的故障-正常分离器
2. **时序预测残差加噪**：GRUPredictor 残差在正常转弯时也大，污染特征空间
3. **手工关联特征冗余**：GRU 权重已隐式编码因果映射，FFT/互相关/协方差零边际贡献
4. **AE 应扩展不应压缩**：78→128→64 提供额外维度给 gravity loss；压缩破坏判别结构。但马氏距离跳过 AE 后性能更好，说明 AE 非必需
5. **GRU > LSTM/Conv1d/TCN**：稠密循环连接对小样本最优
6. **更长历史有帮助**：hist=75 覆盖完整机动周期，样本仅减 7.7%
7. **小模型优于大模型**：39K 样本支撑不了 128 hidden 或 3 层
8. **cmd−meas 是最优预处理**：领域知识的有益注入，原始通道反而加噪
9. **马氏距离 > Galaxy AE+SMM**：两个数据集上均验证。Gravity loss 将正常帧压入单簇，SMM(k=5) 中 4 个空置。协方差矩阵逆即可达到最优，无需神经网络聚类

## 遗留问题

1. **卡中位故障** (3/36 序列 AUC < 0.8)：控制面停在中位，平飞时不可见，仅在操纵瞬间暴露。100% 数据驱动方法对此有本质局限。
2. **升降舵样本不足**：仅 2 条序列，统计不可靠。
